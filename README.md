# OfficeRequest Hub

Enterprise request management solution built with Power Apps, Power Automate and SharePoint.

## Overview

OfficeRequest Hub is an internal enterprise application designed to centralize and automate employee service requests.

## Technologies

| Technology | Purpose |
|---|---|
| Power Apps | Front-end application |
| SharePoint Lists | Data storage |
| Power Automate | Workflow automation |
| GitHub | Version control and documentation |

## Features

- Request submission
- Approval workflow
- Status tracking
- Email notifications
- Dashboard reporting
- Request history audit log
